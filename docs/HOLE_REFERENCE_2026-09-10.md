## 几何约定和算法

`LOADMvCfg` 读取两臂 TYPE=1017、DH、限位及 GRV；初始化各臂后移除工具变换，
将 q 从 rad 转 deg，调用 `FX_Robot_Kine_FK`。此处使用模型初始化后的默认用户坐标。

CCS 实现的法兰固定变换将最后关节的法兰延伸方向映射为法兰局部 +Z；
peg 安装在法兰外侧，取 FK 旋转矩阵第三列为 peg 指向孔内的方向。
这一轴向符号、实际安装及模型重力与现场安装的一致性仍需现场核实。
SDK 文档 `c++_doc_kine.md` 将 GRV 定义为重力方向；本模型为：

- 左臂 GRV = (0, +9.81, 0)，名义上方 u = (0, -1, 0)。
- 右臂 GRV = (0, -9.81, 0)，名义上方 u = (0, +1, 0)。

此处的 u 来自模型，不是现场 IMU 测量，未假设两臂基座 Z 朝上。
以 peg 轴作为用户确认的孔轴代理，不是测量墙面法线。

```text
p = FK(q).R[:, 2]                 # 法兰 +Z，peg 朝孔内
z = -p                           # 孔口朝机器人
y = normalize(u - dot(u,z)*z)     # 实际上方在孔口平面内的投影
x = normalize(cross(y,z))        # 正对孔口的右方
A = [x^T; y^T; z^T]              # 基座力 -> 固定任务坐标力
```

当前得到的轴向与水平面的夹角（按模型重力）约为：左 +0.430°、右 -0.516°。
没有强行把这一小角度归零，保留采集的参考轴向。
由于构造只使用法兰 Z 轴、而不使用法兰 X/Y 作为上方，因此不受 peg 绕自身长轴旋转影响。
固定配置不跟随后续关节姿态更新；改变机器人基座、孔或墙面安装后需要重新采集。

矩阵行对应配置 `screen_right_axis`、`screen_up_axis`、`axial_axis`。
`task_yaw_deg` 均保留 0，避免对已得到的固定几何矩阵重复旋转。
`external_force_sign` 均保留 +1，未凭几何推断外力估计符号。
`wrench_convention_confirmed` 与 `direction_mapping_confirmed` 仍为 false，preview 仍为 true。

验证要求：矩阵正交、det=+1；朝孔内 peg 方向的力映射为任务 -Z；投影后的上方映射为 +Y；
用现场已知方向轻微加载验证轴/符号，并区分“施加外力方向”与反向显示的“接触侧”。
此配置不代表精确接触点估计，也没有进行工具/摩擦/动力学参数标定。
